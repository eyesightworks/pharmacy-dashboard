# Hospital Pharmacy Management System

A responsive hospital pharmacy management platform built with HTML, CSS, and JavaScript for managing medicines, pharmacy inventory, cart operations, and healthcare-related workflows within a clean dashboard interface.

This project demonstrates frontend dashboard development, interactive UI architecture, inventory management workflows, and client-side pharmacy system operations using pure JavaScript.

---

# Project Overview

The Hospital Pharmacy Management System was designed as a healthcare dashboard interface focused on medicine management, pharmacy stock tracking, and cart-based transaction workflows.

The application includes:

- Pharmacy Dashboard
- Medicine Inventory Management
- Cart & Billing Interface
- Login Authentication Screen
- Pharmacy Statistics Dashboard
- Healthcare Image Showcase
- Responsive Admin Layout
- Interactive User Navigation

The system demonstrates frontend architecture and scalable dashboard UI organization for healthcare and pharmacy management applications.
